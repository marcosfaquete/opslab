# OpsLab

Laboratório prático de infraestrutura, Linux, Cloud e DevOps desenvolvido em ambiente real utilizando DigitalOcean.

## Objetivo

Construir, administrar e documentar uma infraestrutura Linux desde o provisionamento inicial até deploy, segurança, banco de dados, observabilidade, backup e automação.

O projeto tem como objetivo estudar na prática conceitos utilizados em administração de sistemas, infraestrutura cloud e DevOps.

## Infraestrutura inicial

- Cloud Provider: DigitalOcean
- Region: NYC1 - New York
- Operating System: Ubuntu 24.04 LTS
- Droplet Type: Basic / Shared CPU
- vCPU: 1
- RAM: 1 GB
- Disk: 25 GB SSD
- Network: Public IPv4
- Estimated Compute Cost: US$ 6/month

## Tecnologias planejadas

- Linux / Ubuntu Server
- SSH
- UFW
- Nginx
- Git
- PostgreSQL
- Docker
- CI/CD
- GitHub Actions
- Prometheus
- Grafana
- Backup e Restore
